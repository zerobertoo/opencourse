# Security Policy

## Reporting a vulnerability

Please do not open a public issue for security problems.

Use GitHub's private reporting: go to the repository's **Security** tab and choose **Report a vulnerability**. Include what you found, how to reproduce it and the affected version or commit.

You can expect an acknowledgement within a few days. We will keep you updated, fix the issue and credit you in the release notes unless you prefer otherwise.

## Supported versions

The project is pre-1.0. Only the latest commit on `main` receives security fixes.

## Scope notes

Download protection for self-hosted videos is limited by design (see [docs/video.md](docs/video.md)); that is documented behavior, not a vulnerability.
